# Reproducible evaluation

The evaluator never discovers or controls real media sessions. It runs the production eye classifier and playback policy against a simulated playing session, acknowledging commands immediately.

## Synthetic trace

```powershell
eyepause-benchmark trace examples/demo-trace.jsonl --output benchmark-results/trace.json
```

The bundled trace is synthetic: 161 samples at 10 Hz with one brief blink, one sustained closure, reopening, and a missing-viewer interval. It is generated by `python scripts/make_demo_trace.py`. Its ground-truth labels are specified by the scenario, not inferred from the production classifier.

A JSONL row has this shape:

```json
{"timestamp": 5.0, "left_ear": 0.1, "right_ear": 0.1, "faces": 1, "label": "closed"}
```

Timestamps must increase strictly and be finite. EAR may be null when unavailable. Labels are `open`, `closed`, or `unknown`. Unknown/multiple faces suspend actions. Gaps above 0.75 seconds break continuity.

## Annotated video

Use a consented local clip and manually label its eye states before inspecting predictions. Copy `examples/annotations.example.json` and replace its example segments with contiguous half-open intervals covering every frame from time zero:

```powershell
eyepause-benchmark clip my-clip.mp4 my-labels.json --compare-legacy --output benchmark-results/clip.json
```

Every decoded frame is processed by Face Landmarker. Video timestamps use frame index divided by the reported FPS; use constant-frame-rate clips. `--compare-legacy` also evaluates Haar-detected eye-region mean brightness on those same frames, using the same new temporal policy. This is a detector comparison, not a claim to reproduce the old scripts' keyboard behavior or frame-counter settings.

Do not commit private clips or generated benchmark files. Commit a shareable report only after documenting consent, labels, dataset composition, hardware, settings, and reproducible commands. Synthetic UI screenshots contain no camera footage.

## Metrics

| Metric | Meaning |
| --- | --- |
| Sample-state accuracy | Fraction of annotated samples classified correctly, including unknown |
| Closed-sample precision / recall | Per-sample closed-eye classification against the labels |
| Closure-event precision / recall | One-to-one matches between pause actions and annotated closures lasting at least the configured pause delay |
| False pauses | Pause actions unmatched to a qualifying closure episode |
| Closure-to-pause | Median/p95 time from closure onset to the simulated pause, including configured dwell |
| Reopening-to-resume | Median/p95 time from subsequent reopening to simulated resume, including configured dwell |
| Inference | Per-frame inference median/p95 for clip mode |
| Processing samples/second | Offline replay or clip-processing throughput, explicitly identified by mode |

Undefined precision/recall is null rather than a fabricated perfect score. Trace throughput measures Python replay, not camera inference. Clip throughput includes decoding and landmark inference, while comparison throughput measures the brightness detector separately. The model's initialization time is excluded. Real Windows/player command latency must be measured independently; it is not represented by the immediate replay acknowledgements.

For hardware evaluation, include ordinary blinks, prolonged closure, winks, glasses, changes in lighting, head turns, leaving/re-entering the frame, and multiple faces. Record false pauses per viewing hour in addition to clip metrics. Avoid broad accuracy claims from a single participant or synthetic trace.
